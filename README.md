# Android DApp WalletConnect Integration Example

This project is a code example demonstrating how to integrate WalletConnect in an Android application to enable DApp wallet connections.

More specifically, it showcases a complete end-to-end flow:

Android App → Chrome / Safari → Public H5 DApp → WalletConnect → Crypto Wallet → Callback to Android App

The goal of this project is to illustrate how an Android app can trigger a DApp connection via a web browser and successfully complete the WalletConnect handshake and wallet authorization flow, then return control back to the original app.
